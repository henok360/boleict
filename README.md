# Bole Support Hub

complete this task with available todays credit. Build a full-stack IT Support Management app for Bole Sub City. Enable Lovable Cloud for authentication and persistent data. Create username/password accounts, profiles, and role-based access for User, Team Leader, and IT Support Engineer. Workflow: Users submit requests; every request goes first to the Team Leader; Team Leader reviews and assigns an IT Support Engineer; engineer accepts the assignment, posts responses/progress updates, and marks work completed; User confirms completion, which is visible to the Team Leader for closure. Include dashboards tailored to each role, ticket status/history, notifications, and a professional municipal IT support interface. add a super admin with a role of delete accounts, reset every ones pass word, generate 3 types of 4 digit pass key for every one who crates a new account, this pass keys are 3 types, the first pass key is for uses, the second pass key is for it engineers, the third pass key is for the team leader, with out this pass key a new account creation should not be allowed, the admin can change this pass keys at any time which will be applicable only for new account creators only, there is only one and only one super admin, once a super admin account is crated an option to be super admin should be removed for others when crating account.
